📌 Featured project
📅 Bakaláři Timetable Widget

<a href="https://github.com/VitekCharvat/bakalari-rozvrh-widget/releases"><img src="https://img.shields.io/github/v/release/VitekCharvat/bakalari-rozvrh-widget?style=flat-square&color=2F81F7" alt="Latest release" /></a> <img src="https://img.shields.io/badge/platform-iOS%2016%2B-black?style=flat-square&logo=apple" alt="iOS 16+" /> <img src="https://img.shields.io/badge/built%20with-Scriptable-2F81F7?style=flat-square" alt="Built with Scriptable" />

Your Bakaláři school timetable right on the iPhone home screen, so you don't have to open the app to see where your next lesson is. It runs in Scriptable, which means no Mac and no paid Apple developer account.

Live countdown for the lesson that's running right now
Substitutions and cancelled lessons highlighted, plus optional notifications for changes in the next 7 days
Works offline with the last downloaded timetable
Any school that uses Bakaláři, light and dark mode included

The widget is in Czech, since Bakaláři is a Czech school system.
